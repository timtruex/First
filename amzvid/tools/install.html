amzvid Capture

One action on an Amazon listing sends the title, bullets, price and photos to your bot. Two ways in: a bookmarklet on the Mac, a Shortcut on the phone.

On iPhone

Share sheet in Safari. About ten minutes to set up, once.

Before you start

  1. Turn on scripting. Open the Settings app → Apps → Shortcuts → Advanced, and switch on Allow Running Scripts. Shortcuts refuses to run JavaScript until you do, and the error it gives does not say so clearly. On older iOS this lives at Settings → Shortcuts → Advanced.
  2. Get your two Telegram values. In Telegram, message @userinfobot and it replies with your numeric Id — that is your chat_id. Your bot token came from @BotFather when you created the bot; it looks like 8123456789:AAH....

Build the shortcut

  1. Open Shortcuts and tap + (top right) to start a new one.
  2. Tap New Shortcut at the top and rename it amzvid Capture.
  3. Tap Add Action, search for Run JavaScript on Web Page, and tap it.
  4. Tap the grey placeholder script inside that action. Select all of it, delete it, and paste the JavaScript from the button above.
  5. Tap Add Action again, search Get Contents of URL, and tap it.
  6. In the URL field, type:
    https://api.telegram.org/botYOUR_TOKEN/sendMessage
    with your real token in place of YOUR_TOKEN. Keep the word bot immediately before it, with no space.
  7. Tap the small > (or Show More) on that action to expand it.
  8. Set Method to POST.
  9. Set Request Body to Form. (JSON also works but takes more taps and has been buggy in some versions.)
  10. Tap Add new field → Text. Key: chat_id. Value: your numeric id from @userinfobot.
  11. Tap Add new field → Text again. Key: text. For the value, tap the field, then tap the variable button just above the keyboard and choose JavaScript Result. It should appear as a blue pill, not as typed-out words.
  12. Open the shortcut's settings — the ⓘ button at the bottom, or the toggles icon at the top right depending on your iOS version — and switch on Show in Share Sheet.
  13. Still in there, tap Share Sheet Types and turn everything off except Safari web pages. Without this the shortcut shows up where it cannot work.
  14. Tap Done.

Using it

  1. Open the Amazon listing in Safari. The Amazon app will not work — this action only reads Safari pages.
  2. Scroll the photo gallery once so the images load. The capture reads what the page has actually loaded.
  3. Tap Share → amzvid Capture. You may have to scroll down the share sheet, or tap Edit Actions once to pin it.
  4. The first time, iOS asks whether to allow the shortcut to run on that site. Tap Allow.
  5. Check Telegram. The bot replies with the script and a Render button.

If it does not work

  1. Nothing appears in Telegram. Run the shortcut once from the Shortcuts app with an Amazon page open in Safari, and watch the Get Contents of URL result. Telegram answers with {"ok":false,"description":"..."} and the description names the problem — usually a wrong token or chat id.
  2. The shortcut hangs or times out. Almost always Allow Running Scripts being off.
  3. The bot replies "scroll the photo gallery once". The capture worked but the page had not loaded its images yet. Scroll and share again.
  4. The shortcut is missing from the share sheet. Check Show in Share Sheet is on and that Safari web pages is among the allowed types.

On the Mac

Bookmarks bar in any desktop browser.

amzvid Capture

Drag this to your bookmarks bar. Clicking it here does nothing.

  1. Show the bookmarks bar: ⇧⌘B in Chrome, View → Show Favourites Bar in Safari.
  2. On a listing, scroll the photo gallery once so the images load, then click the button. A green banner confirms what it copied.
  3. Paste into Telegram, or run amzvid watch and it is picked up automatically.
Why this and not a scraper. Both routes run in your own browser, on a page you are already looking at, when you act. There is no automated request to Amazon, so there is nothing to rate-limit or block, and it stays clear of the Associates agreement's bar on automated access. It is a structured copy-paste.
